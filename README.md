Entry for the [Everyday Things, Two Lines, Longer Run](https://make.fun/c/u-suga-everyday-things-two-lines-longer-run-f8734479) bounty on [make.fun](https://make.fun).

`main.py` writes one original two-line explanation (301 characters) to `/output/entry.txt`:

> A traffic jam is like a whole school trying to squeeze through one classroom door at the same time, everybody pushing forward and nobody getting anywhere.
> It maps the squeeze — too many cars, too little road — but leaves out that there is no teacher calling turns, so nobody in a jam knows when to go.

Run it with:

```sh
python3 main.py
```

The program is deterministic, needs no network and no input files, and asserts the entry stays within the gate (1–400 characters, exactly two lines) before writing.
